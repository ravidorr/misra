Contact

Misra is run by one person, the maintainer. Choose the route below that fits what you need.

Questions, bugs and suggestions

Open an issue on GitHub. You need a GitHub account. Issues are public, so leave personal details out.

Security problems

Do not open a public issue. Report it privately, as the security note describes.

Email the maintainer

Write to the maintainer about your data (to see, correct or delete it, or to make a complaint), or about anything else if you have no GitHub account. The privacy notice gives the address.
